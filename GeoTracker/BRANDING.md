# GeoTracker naming

GeoTracker is the product name used by the frontend, API, launchers, package metadata, documentation, and logs.

The checkout directory is GeoTracker. Commands and repository ignore rules use the new path.
Existing persistence identifiers are intentionally retained: backend/geotrench.db, C:\\GeoTrench storage directories, and the GeoTrench Windows Firewall rule group/prefix. These are compatibility identifiers, not product branding. Renaming them requires migrating existing database and quarantine records and cleaning up or migrating active firewall rules.
