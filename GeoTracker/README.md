# GeoTracker

Education-first network awareness and security insights.

## Install, build, and start

From this directory:

```sh
python manage.py install
python manage.py build
python manage.py start
```

Requires Python 3.11+ and Node.js 22. Open http://localhost:8000 after starting. PORT can select another port. Stop any running Vite dev server before reinstalling dependencies on Windows.

See [Render deployment](DEPLOYMENT.md) for native Python build/start commands, environment variables, and the difference between hosted learning and local Windows monitoring.
